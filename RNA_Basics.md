# RNA Folding Basics

RNA consists of:

A = Adenine
U = Uracil
C = Cytosine
G = Guanine

Valid Base Pairs:

A-U
U-A

C-G
G-C

RNA folds into structures.

The most stable structure is called:

Minimum Free Energy (MFE)

ViennaRNA predicts MFE structures.

Dot-Bracket Notation:

. = unpaired

( = opening pair

) = closing pair
